# Photopea & Pixlr Tools, Filters, Effects & Features (Combined 2026)

> Reference: Photopea (full PSD-compatible browser editor) + Pixlr (AI-powered
> editor). Used as a gap-analysis source for Inkception. See
> `PS-ROADMAP.md` + `PS-COMPARE.md` for the implementation plan.

## 1. Tools in the Toolbar

**Common (both)**: Move (V) · Crop (C) · Hand (H) · Zoom (Z) · Eyedropper (I) ·
Rectangular/Elliptical Marquee (M) · Lasso / Polygonal Lasso (L) · Magic Wand
(W) · Quick/Object Selection (W)

**Photopea extras**: Single Row/Column Marquee · Magnetic Lasso · Content-Aware
Select · Pen/Freeform/Curvature Pen + anchor editing · Clone Stamp (S) ·
Healing Brush / Patch / Spot Healing (J) · Gradient / Paint Bucket (G) · Blur /
Sharpen / Smudge (R) · Eraser / Background Eraser / Magic Eraser (E) · Dodge /
Burn (O) · Brush / Pencil (B) · all shape tools (U) · 3D (K, extended) ·
Content-Aware Move/Replace (J)

**Pixlr extras**: Color Replacement (B) · Spot Heal / Object Remove / AI
Remove (floating AI bubble) · Liquify · Generative Fill / Expand · Remove
Object · Super Scale · AI Avatar / Face Swap / Sticker Maker / Backdrop ·
Batch editing · AI Smart Resize · templates (X mode) · collage / double
exposure / text wrap / color splash / glamour effects
